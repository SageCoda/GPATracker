
#  GPATracker 

**GPATracker** is a mobile application built with **React Native** that allows students to track and calculate their GPA across multiple semesters.

---

##  Features

- Input courses with grades and credit units
- Automatically calculate GPA for each semester
- Organize semesters under academic years (e.g. Year 1, Year 2)
- Offline-first experience using AsyncStorage

---

## Tech Stack

- **Frontend**: React Native (Expo)
- **Language**: TypeScript
- **Data Storage**: AsyncStorage (local-only, no backend yet)
- **Navigation**: Expo Router + Tabs

---


## Future Ideas (Post-POC)

- Backend support for syncing data across devices
- GPA projections and "What-if" analysis
- Login and user management
- Analytics dashboard
